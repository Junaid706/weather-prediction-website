About WeatherPredict

An advanced weather prediction system powered by AI and machine learning.

Features

  • Current Weather: Real-time conditions including temperature, humidity, pressure, and wind data.
  • 5-Day Forecast: Extended forecast with high/low temperatures and confidence indicators.
  • 24-Hour Forecast: Hourly weather predictions.
  • AI Prediction: Machine learning model (Polynomial Regression) predicts future temperatures based on historical patterns.
  • Historical Data: 30-day historical temperature trends.
  • Search History: Track your recent city searches.

Technology Stack

  • Django 5.2
  • Python 3.12
  • scikit-learn
  • Bootstrap 5
  • Chart.js
  • SQLite

Data Source

Demo Mode: This site currently uses simulated weather data for demonstration purposes. To use real weather data, integrate with a weather API (e.g., OpenWeatherMap, WeatherAPI) by adding an API key to your environment variables and updating the services.py module.
